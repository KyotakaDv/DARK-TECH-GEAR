# ⚡ DARKGEAR | Minimal Cyber Store

> Uma plataforma de e-commerce full-stack com visual dark/cyberpunk, painel administrativo integrado e arquitetura segura, desenvolvida para alta performance.

---

## 🚀 Tecnologias Utilizadas

* **Back-end:** Node.js, Express, Mongoose (MongoDB Atlas).
* **Front-end:** HTML5, CSS3 (Design Neo-Brutalist/Cyberpunk), Vanilla JavaScript.
* **Ambiente de Desenvolvimento:** Termux & Android Stack.

---

## ⚙️ Como Executar o Projeto

Certifique-se de ter o **Node.js 18+** instalado em seu ambiente (como o Termux no Android ou PC).

1. **Clone o repositório e acesse a pasta do projeto:**
   ```bash
   git clone [https://github.com/seu-usuario/DARK-TECH-GEAR.git](https://github.com/seu-usuario/DARK-TECH-GEAR.git)
   cd DARK-TECH-GEAR
   npm install
   npm run seed && npm start
